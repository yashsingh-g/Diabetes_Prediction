# Diabetes Prediction using Machine Learning

## Overview
This project predicts whether a person is likely to have diabetes using machine learning algorithms based on medical attributes such as glucose level, blood pressure, BMI, insulin, age, and other health parameters.

## Features
- Data preprocessing and cleaning
- Correlation analysis
- Feature engineering
- Model training using K-Nearest Neighbors and Random Forest
- Model comparison and evaluation
- Flask web application for real-time predictions

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS

## Dataset
- Pima Indians Diabetes Dataset

## Installation

```bash
git clone https://github.com/yashsingh-g/Diabetes_Prediction.git
cd Diabetes_Prediction
pip install -r requirements.txt
python app.py
```
